# attic / bathroom-private｜场景蒙版与角色姿态预案

本笔记是两间房的后续适配模板，不是坐标表，也不是运行时代码。对应背景图生成并确认构图后，才把语义锚点翻译成实际画布坐标、透明蒙版范围和可交互落脚点。

## 0. 统一合同

### 0.1 场景镜头合同

- 两间房都使用横向 `1536×1024` 画布和固定三分之四视角；相机高度、地板透视、光照方向和纸板舞台的观看距离保持稳定。
- 背景图是干净的空场景背板：不烘焙角色、角色影子、对白、UI、状态文字或可读文字。
- 任何蒙版先用语义锚点命名，暂不填写 `x/y/width/height`；背景图到位后再以画布像素或归一化坐标建立映射。
- 蒙版只解决景深和边界，不用来修补错误背景。阁楼缺少可辨识梯口，或浴室出现门内像素时，应退回背景图重生成，不能用前景蒙版遮掩后当作合格资产。
- 角色移动区、停靠区、遮挡区和隐私边界是四种不同概念：移动区用于路径，停靠区用于落脚，遮挡区用于前后景关系，隐私边界用于禁止穿越或透视。

### 0.2 角色合同

以现有 `novelist` 角色合同为唯一基准。后续新姿态是同一个纸板人偶的姿态扩展，不是新角色：

- 保持同一轮廓、同一服装气质、同一有限棕蓝暖色配色和同一纸板材质。
- 保持圆弧纸板底座、无可见脚部、无真实人体写实细节；如果场景遮挡底座，只能由真实前景物件遮挡，不能改画成脚踩梯级。
- 保持耳后的褪色红色书签作为识别标记；不得因侧身、爬梯或弯腰姿态丢失或改成其他饰物。
- 角色素材保持透明背景、无文字、无水印；角色不携带新 logo、门牌或道具字样。
- 角色姿态变化只表达动作，不改变人物身份、比例、头部风格和纸板边缘。影子、灯光晕染和遮挡优先由场景层/运行时层处理，不画死在角色源图里。
- 现有基础姿态仍是 `walking`、`standing`、`seated`。`climbing-ladder`、`archive-search`、`knock` 是待背景确认后的候选扩展，不在本笔记阶段写入 manifest 或代码。

### 0.3 坐标延期合同

当前只登记以下语义占位符：

`[SCENE_FRAME]` · `[ACTOR_LANDING]` · `[ACTOR_HITBOX]` · `[WALKABLE_CLEAR]` · `[FOREGROUND_OCCLUDER]` · `[PRIVACY_BOUNDARY]`

实际背景图生成后，逐一补充：

1. 背板中固定物件的像素边界；
2. 角色圆弧底座最低点的落脚点；
3. 角色业务 hitbox（不从透明像素自动推断）；
4. 前景蒙版的可见边界和遮挡比例；
5. 动作终点与不可穿越边界。

在此之前不写猜测坐标，不把当前测试画布尺寸或旧房间坐标迁移到新场景。

## 1. attic｜阁楼适配模板

### 1.1 固定场景锚点

| 语义锚点 | 预期内容 | 坐标状态 | 适配原则 |
| --- | --- | --- | --- |
| `[ATTIC_LADDER_ENTRY]` | 左侧偏后的矩形楼板活板门与向下梯子入口 | 待背景图 | 必须是可通行入口；不能是装饰梯、断梯或悬空梯 |
| `[ATTIC_LADDER_RECESS]` | 活板门下方的深色不可透视区域 | 待背景图 | 只表示深度；不展示楼下房间、街道或人物 |
| `[ATTIC_SKYLIGHT]` | 后方偏右的小天窗与冷蓝夜色 | 待背景图 | 属于背景光源，不是第二个可进入场景 |
| `[ATTIC_ARCHIVE_STACK]` | 靠墙或靠斜屋顶的书堆、旧箱子、查档面 | 待背景图 | 书脊和纸页无可读文字；不侵入移动通道 |
| `[ATTIC_WALKABLE_CLEAR]` | 前景至中部的连续旧木地板移动区 | 待背景图 | 供人偶靠近书堆或梯口；保持平整、不中断 |
| `[ATTIC_LADDER_STOP]` | 梯口外侧的接近/停留边界 | 待背景图 | 角色可到达边缘；不能让镜头或角色穿入楼下 |

### 1.2 蒙版层次预案

只使用语义层，不提前规定数值 z-index。最终顺序由背景图的真实景深确认，但必须满足下列关系：

1. **背景层**：阁楼墙面、斜顶、旧木地板、天窗、书堆主体和暖黄/冷蓝光照。
2. **天窗光层**：只在 `[ATTIC_SKYLIGHT]` 周边做冷蓝色的柔和光洗，位于角色之后；不得把角色剪成黑色剪影，不得露出窗外可识别地点。
3. **角色层**：使用统一纸板人偶透明素材，底座最低点对齐 `[ACTOR_LANDING]`；不能把角色直接绘制进背板。
4. **书堆前景遮挡层**：仅在 `archive-search` 需要空间纵深时启用；遮挡角色底座或下半身的范围要由书堆真实边缘决定，不能盖住识别标记、主要动作手势或把角色裁成残缺人体。
5. **梯子前景遮挡层**：在 `climbing-ladder` 时启用梯子侧梁、近侧踏棍或活板门边缘的遮挡；遮挡应让角色与梯子发生接触，但不能把角色完全抹掉，也不能制造“脚踩真实梯级”的写实人体效果。
6. **外部状态层**：只承载灯光小变化、无字稿纸、事件标记或动作反馈；不改变梯口、天窗和移动区的固定关系。

蒙版命名预案：

| 蒙版名 | 类型 | 作用 | 永远不能遮挡 |
| --- | --- | --- | --- |
| `attic-ladder-recess-mask` | 背景深度 | 维持梯口向下的不可见深处 | 不得暴露楼下内容 |
| `attic-ladder-front-occluder` | 前景遮挡 | 让侧梁/梯级在爬梯姿态前方成立 | 不能遮住整个人偶或书签 |
| `attic-archive-stack-front-occluder` | 前景遮挡 | 让查档时的书堆有近景层次 | 不能遮住查档手势和上半身识别 |
| `attic-skylight-light-matte` | 光照层 | 延续冷蓝夜景 | 不能把人偶变成剪影 |
| `attic-walkable-clear-mask` | 保护区 | 标记不可放置家具/前景物的移动区 | 不作为可见图形输出 |

### 1.3 角色姿态预案

#### A. 走向梯口：复用 `walking`

- 角色从 `[ATTIC_WALKABLE_CLEAR]` 靠近 `[ATTIC_LADDER_ENTRY]`，仍使用现有摇摆移动姿态。
- 接近时只做自然的减速和朝向变化，不突然缩放、不穿过书堆、不跨过活板门边缘。
- 到达 `[ATTIC_LADDER_STOP]` 后转为 `standing` 或待生成的 `ladder-contact`；不在梯口前凭空消失。

#### B. 梯口接触：候选 `ladder-contact`

- 作为 `standing` 的轻扩展：身体朝向梯口，肩线略偏，单手接近侧梁，另一只手保持在身体前侧。
- 圆弧底座仍落在阁楼地板外侧，不能画出脚、鞋或跨入楼板开口的腿部。
- 梯子侧梁可在角色前方形成局部遮挡，但要保留头部轮廓、书签、上半身和接触手势。
- 这是“确认入口”的停留姿态，不表示已经进入楼下；背景仍是同一张阁楼背板。

#### C. 爬梯：候选 `climbing-ladder`

- 作为独立的透明角色姿态候选，不在本阶段直接替换现有 `walking/standing/seated`。
- 采用侧后方三分之四的纸板姿态：躯干沿梯子方向轻微前倾，一只手扶近侧梁，另一只手向上方踏棍延伸，头部朝向上方但不露出新的脸部细节。
- 仍保持同一人物轮廓、耳后褪色红书签、纸板边缘和圆弧底座合同；下半身若被梯子遮挡，必须由 `attic-ladder-front-occluder` 解释，而不是添加真实脚部。
- 动作只允许发生在梯口到阁楼这一段可见空间内；不生成楼下视角、下层房间、手脚从黑暗处伸出或相机跟随进入洞口。
- 动画预案按“接近 → 扶梁停顿 → 短距离爬行 → 在阁楼侧重新站稳”分段；每段都保持同一画布、同一角色朝向逻辑和同一隐私/深度边界。

#### D. 查档：候选 `archive-search`

- 作为 `standing` 的上半身动作扩展：身体在 `[ATTIC_ARCHIVE_STACK]` 前轻微前倾，一只手抽取无字书册或翻开无字档页，另一只手扶住箱盖/书堆边缘。
- 书堆、箱子和纸页必须没有可读文字；“查档”由手势、空白纸面和物件关系表达，不由标题或文字表达。
- 角色底座保持稳定落在旧木地板上；不做跪姿写实化、不生成脚、不让书堆遮掉头部、书签和主要手势。
- 查档结束后回到 `standing`，再按需要转为 `walking`；不能通过角色切换把人偶瞬移到天窗或梯口。

### 1.4 attic 状态边界

- `quiet`：只有空场景、暖黄台灯、冷蓝天窗和可辨识梯口；不需要角色。
- `archive-search`：可启用查档姿态和书堆前景遮挡；梯口深处仍不可见，书堆不扩张到移动区。
- `climbing`：可启用爬梯姿态和梯子前景遮挡；不生成任何楼下内容，梯口是不可透视边界。
- `away`：复用 `walking` 离开阁楼的动作语义；不生成“角色已在楼下”的新场景，不改背景镜头。
- 背景图中不能表达“角色进入了下层”；如业务需要记录该事件，交给外部状态数据或文字层，不能靠图像泄露。

## 2. bathroom-private｜浴室隐私边界适配模板

### 2.1 固定场景锚点

| 语义锚点 | 预期内容 | 坐标状态 | 适配原则 |
| --- | --- | --- | --- |
| `[BATHROOM_DOOR_OUTSIDE_NODE]` | 完全关闭的浴室门、外侧门框和把手 | 待背景图 | 这是唯一可见的浴室节点；门内永远不生成 |
| `[BATHROOM_THRESHOLD_OUTSIDE]` | 门前外侧的旧木地板与停留边界 | 待背景图 | 角色只能到这里，不能穿门或被门遮挡后继续移动 |
| `[BATHROOM_KNOCK_POINT]` | 门外可敲门的外侧门面区域 | 待背景图 | 必须留出手势可读空间；门保持关闭、实心、不透光 |
| `[BATHROOM_HANDLE]` | 外侧门把手 | 待背景图 | 只表达外侧物件，不生成锁芯特写或门内反射 |
| `[BATHROOM_EXTERNAL_CLUE_SLOT]` | 门外可承载非隐私线索的外部区域 | 待背景图 | 后续只叠加外部、可撤销、无文字的线索层 |
| `[BATHROOM_WALKABLE_CLEAR]` | 从公共动线来到门前、再离开的地板通道 | 待背景图 | 通道不被脚垫、篮子、衣物等杂物堵住 |
| `[BATHROOM_PRIVACY_BOUNDARY]` | 关闭的门叶、门缝和门框组成的不可穿越边界 | 待背景图 | 不是可解锁蒙版，不是待生成的内部占位区 |

### 2.2 蒙版层次预案

浴室的“内侧”不是一个可供合成的图层。所有状态都必须在门外完成：

1. **外部背板层**：公共动线、旧木地板、斑驳墙面、关闭门、门框和外侧把手。
2. **不透明隐私层**：把门叶、门缝和门框视为连续的实心边界；不允许透明、半透明、透光、反射或门后轮廓。
3. **角色层**：`knock`、`standing` 或 `walking` 只出现在门外，底座落在 `[BATHROOM_THRESHOLD_OUTSIDE]` 之前。
4. **外部节点/线索层**：只放在门外的 `[BATHROOM_EXTERNAL_CLUE_SLOT]`，且必须是独立、可撤销、无文字的叠加；不得把线索从门内“投影”出来。
5. **状态/交互层**：敲门、等待、离场和不可达状态由事件与界面表达；不改变门的开合，不切换到门内镜头。

蒙版命名预案：

| 蒙版名 | 类型 | 作用 | 永远不能出现 |
| --- | --- | --- | --- |
| `bathroom-door-opaque-mask` | 隐私边界 | 将门叶、门缝和门框保持为不可透视实心面 | 浴缸、马桶、镜子、淋浴、人体轮廓、室内光 |
| `bathroom-threshold-stop-mask` | 交互保护区 | 标记人偶可停留的门外边界 | 不作为可见黑条，不把角色切成残片 |
| `bathroom-knock-clear-mask` | 动作保护区 | 为敲门手势保留门外可读空间 | 不遮住手势，也不让手穿入门内 |
| `bathroom-external-clue-overlay` | 外部叠加 | 承载离场后仍可被看见的公共线索 | 不承载个人隐私、声音、气味、室内残留或文字 |
| `bathroom-no-interior-layer` | 永久禁用 | 明确不存在可加载的浴室内部图层 | 任何状态、过渡、失败回退都不能生成内部 |

### 2.3 角色姿态预案

#### A. 门外接近：复用 `walking`

- 角色沿 `[BATHROOM_WALKABLE_CLEAR]` 接近 `[BATHROOM_THRESHOLD_OUTSIDE]`，保持同一纸板人偶和同一底座合同。
- 接近动作在门前外侧自然减速；不让人偶脚下出现脚印，不让影子投进门缝，不让角色穿过门叶。
- 到达门前后转为 `standing` 或候选 `knock`；不通过淡出、裁切或镜头跟入制造“已经进门”的错觉。

#### B. 敲门：候选 `knock`

- 作为 `standing` 的轻扩展：身体面向关闭的门，单手抬到外侧门面附近，手指只接触门外表面；另一只手自然下垂或抱住空白纸张。
- 圆弧底座完整落在门外地板，门槛是不可穿越边界；不画开门缝、门内手、门内脚、门后影子或门缝光。
- 轻微的“敲门”动势可以由手臂的两个离散帧表达，但两帧都只能存在于门外；背景背板不因敲门改变。
- 敲门不是“探视内部”的动作，角色视线/头部方向只服务于外侧门面，不增加偷窥视角。

#### C. 门外等待：复用 `standing`

- 角色站在 `[BATHROOM_THRESHOLD_OUTSIDE]` 前方的安全停留区，手臂回到中性位置。
- `private` 或 `locked` 状态不新增人物暗示：门、门缝、把手和墙面保持同一张背板，等待状态不能通过室内光、蒸汽、轮廓或声音可视化表达。
- 如果必须表示“暂时不可达”，只在外部状态层显示说明或让角色保持等待，不生成锁具特写和内部预览。

#### D. 离场：复用 `walking`

- 角色从门前外侧转身离开，回到 `[BATHROOM_WALKABLE_CLEAR]`；离场过程中不回头窥视，不触碰把手，不把手伸向门缝。
- 离场结束后角色可以从场景中离开，但浴室背板仍保持关闭门外的 canonical 图，不切换视角、不显示门内。

#### E. 离场后线索：不新增角色姿态

- `after-leave` 不生成一个“浴室内部发生过什么”的姿态，也不让角色残影停在门边。
- 只允许在 `[BATHROOM_EXTERNAL_CLUE_SLOT]` 叠加已经在门外可被合理看见的、无文字、非敏感的外部线索；该线索必须可撤销，且不需要解释门内发生了什么。
- 可接受的线索语义：门外原有物件的状态变化、角色离开后留下的公共动线变化、或一张不含可读文字的空白纸片/标记层（若故事真源明确需要）。
- 不接受的线索语义：门内声音的可视化、门缝光、蒸汽、湿脚印、衣物、身体局部、镜面反射、浴室用品、可推断占用者身份的个人物品。

### 2.4 bathroom-private 状态边界

- `quiet` / `available` / `private` / `locked` 共用同一张关闭门外背板；状态差异交给事件、界面或无隐私风险的外部节点，不做室内图像变体。
- `knock` 是门外动作，不是开门请求的视觉化；敲门前后门叶、门缝和门把手的隐私属性不变。
- `leave` 只改变角色是否在外部通道，不改变浴室背板；`after-leave` 只允许外部线索叠加。
- `transition` 永远没有“门打开一瞬间”“从门缝看进去”“黑屏遮住内部后再恢复”的中间帧；如果需要转场，使用外部背板的淡入淡出或纯文本状态，不调用内部素材。
- 任一生成结果出现浴室内部、透光、轮廓、身体局部或偷窥视角，直接标记为失败，不进入蒙版适配，不通过裁切补救。

## 3. 待背景图到位后的填写顺序

1. 先确认背景图是否满足统一镜头、空场景、移动区和隐私边界；不合格背景不进入下一步。
2. 记录 `[SCENE_FRAME]` 和固定物件的像素边界，但保持房间锚点名称不变。
3. 标出 `[ACTOR_LANDING]`、`[ACTOR_HITBOX]`、`[WALKABLE_CLEAR]` 与 `[FOREGROUND_OCCLUDER]`，分别服务落脚、交互、路径和景深。
